# Pilates App

SaaS multi-tenant para gestión de estudios de pilates: reservas, agenda, alumnos, pagos online y notificaciones automáticas.

## Stack
- React 19 + Vite 8
- React Router 7
- Tailwind CSS 3.4
- Firebase (Auth + Firestore)
- EmailJS
- Deploy: Vercel

## Setup local
```bash
npm install
cp .env.example .env.local  # completar variables
npm run dev
